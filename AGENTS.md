# Agent Guidelines

These instructions apply to the entire repository.

## Workflow
- Use a PR-driven workflow. Commit on a branch and open a PR.
- Confluence is the source of truth for specifications. Do not edit `SpecsMirror/` manually.
- If a behavior change is required, ensure there is either:
  - an updated Confluence spec, or
  - a migration doc in `Docs/Migrations/`.

## PR Requirements
- PR body must include:
  - **Feature-Key** (e.g., `FTR-0123`)
  - **Confluence page ID** and/or **URL**
- Reference the spec in Confluence and, if applicable, the mirrored file in `SpecsMirror/<Feature-Key>/spec.md`.

## Repository Structure
- `Docs/` is reserved for migration documents only.
- `SpecsMirror/` is auto-generated by the Confluence sync workflow.
- `SpecsMirror/README.md` explains the generated nature of the mirror.
